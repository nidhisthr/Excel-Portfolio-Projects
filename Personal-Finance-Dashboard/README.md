# Personal Finance Tracker & Dashboard

## Project Overview
This project is a comprehensive **Personal Finance Management Tool** designed to track income, expenses, and savings goals. It provides a high-level view of financial health, helping users visualize where their money goes and how to optimize their spending habits.

## Features & Technical Implementation

### 1. Automated Expense Tracking
* **Categorization:** Implemented logic to automatically categorize transactions (e.g., Housing, Food, Transport, Entertainment).
* **Monthly Trends:** Built line charts to track spending fluctuations over the course of the year.

### 2. Financial KPIs (Key Performance Indicators)
The dashboard highlights critical financial metrics:
* **Total Income vs. Total Expenses:** A side-by-side comparison to track net savings.
* **Expense Breakdown:** A pie/doughnut chart showing the percentage of budget spent per category.
* **Savings Rate:** Calculated metrics showing how much of the total income is being saved.

### 3. Interactive Design
* **Dynamic Slicers:** Users can filter the dashboard by **Month** or **Category** to see specific spending details.
* **Modern Interface:** Utilizes a clean, organized layout with high-contrast visuals for easy financial monitoring.

## Key Insights & Benefits
* **Spending Awareness:** Identified "hidden" costs in non-essential categories (like subscriptions or dining out).
* **Budget Variance:** Visual indicators show when spending exceeds the monthly planned budget.
* **Financial Planning:** Provides a historical data view to help predict future savings and investment capacity.
