# Excel-Portfolio-Projects

Welcome to my professional portfolio. This repository serves as a showcase of my ability to transform complex datasets into clear, actionable business insights using **Microsoft Excel**.

**Professional Overview**
I am a Data Analyst dedicated to uncovering the "story" behind the numbers. I focus on creating structured, user-friendly, and interactive tools that allow stakeholders to explore data and make informed decisions quickly.

**Core Data Competencies**

### 1. Data Cleaning & Transformation
I ensure data integrity by preparing raw datasets for analysis. This includes:
* Standardizing data formats and removing duplicates.
* Handling missing values and correcting data entry errors.
* Using **Advanced Formulas** (VLOOKUP, INDEX/MATCH, nested IF statements) to create calculated columns.

### 2. Analytical Processing
I use robust Excel features to slice and dice data, including:
* **Pivot Tables:** Summarizing large datasets to find trends and patterns.
* **Data Modeling:** Connecting different data sources for a holistic view.
* **Statistical Analysis:** Calculating averages, medians, and growth percentages.

### 3. Data Visualization & Dashboards
I build interactive reporting tools that are easy to navigate:
* **Dynamic Charts:** Line, Bar, and Doughnut charts that update automatically.
* **Interactive Slicers:** Allowing users to filter data by Region, Gender, or Category with one click.
* **Professional UI:** Designing clean, "Dark Mode" or high-contrast interfaces for better readability.


## Portfolio Objectives
The projects housed in this repository demonstrate a full end-to-end data workflow:
1.  **Extract:** Importing data from CSV or SQL sources.
2.  **Clean:** Preparing the "Working Sheet."
3.  **Analyze:** Building the logic in Pivot Tables.
4.  **Visualize:** Presenting the final "Dashboard."
