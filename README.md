# Excel Data Analytics Portfolio

This repository showcases three Microsoft Excel projects focused on preparing data, analysing business performance, and presenting findings through interactive dashboards. Each project uses spreadsheet-based analysis to make key metrics and trends easier to understand.

## Portfolio Projects

### 1. Bike Sales Analysis Dashboard

**Project folder:** [`Bike-Sales-Dashboard/`](./Bike-Sales-Dashboard/)

Analyses purchase behaviour in a bike-customer dataset containing 1,000 customer records. The dashboard explores how customer characteristics such as age, income, gender, region, and commute distance relate to purchase decisions.

**Analysis and dashboard work**

- Removed duplicate records and standardised commute-distance categories.
- Created age brackets with Excel formulas.
- Used PivotTables to compare average income by purchase status and gender, purchase counts by age group, and commute patterns.
- Built an interactive dashboard with slicers for gender, region, and education.

**Findings documented in the project**

- The 31–54 age group is the most active purchasing segment.
- Customers with a 0–1 mile commute are the most likely to purchase a bike.
- Customers who purchased a bike have a higher average income than customers who did not.

**Files:** `Bike_Sales_Dashboard.xlsx`, `dashboard_preview.png`, and `Bike_Sales_Demo.mp4`.

[Open the project README and dashboard preview](./Bike-Sales-Dashboard/README.md)

### 2. Personal Finance Tracker and Dashboard

**Project folder:** [`Personal-Finance-Dashboard/`](./Personal-Finance-Dashboard/)

A spreadsheet-based finance tracker designed to monitor income, expenses, savings, and budget performance over time.

**Analysis and dashboard work**

- Categorised transactions into spending groups such as housing, food, transport, and entertainment.
- Created monthly spending trend visualisations.
- Compared total income, total expenses, and savings rate.
- Used a category-level expense breakdown to show where money is allocated.
- Added slicers for month and category, with visual indicators for budget variance.

**Files:** `Personal_Finance_Dashboard.xlsx`, a dashboard preview image, and `Personal Finance Dashboard.mp4`.

[Open the project README and dashboard preview](./Personal-Finance-Dashboard/README.md)

### 3. Vrinda Store Annual Sales Analysis

**Project folder:** [`Vrinda-Store-Analysis/`](./Vrinda-Store-Analysis/)

Analyses annual retail sales data to explore order trends, customer demographics, sales channels, and regional performance.

**Analysis and dashboard work**

- Standardised order-status values and created customer age groups.
- Extracted month information from order dates to review seasonality.
- Compared monthly sales with order volumes.
- Analysed sales contribution by gender, order status, and state.
- Added slicers for product category, sales channel, and month.

**Findings documented in the project**

- Women account for approximately 64% of sales in the analysed dataset.
- Sales show seasonal peaks during selected months.
- The dashboard compares orders across online marketplaces including Amazon, Flipkart, and Myntra.

**Files:** `Vrinda Store Data Analysis.xlsx`, a dashboard preview, and `Vrinda Store Dashboard.mp4`.

[Open the project README and dashboard preview](./Vrinda-Store-Analysis/README.md)

## Notes for Portfolio Review

The findings above describe the datasets included with the respective exercises; they should not be interpreted as conclusions about the wider market. Add the original dataset source, date range, and any relevant data dictionary to each project README so another analyst can understand the context and reproduce the analysis.
